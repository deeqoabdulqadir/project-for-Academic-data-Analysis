# 🔄 3. Pivot Table Analysis

## Dimensional Analysis & Interactive Filtering

Pivot Tables were used to summarize and explore the academic dataset from different perspectives. They helped identify patterns in student enrollment, attendance, and academic performance.

* **Program Distribution:** Pivot Tables were used to analyze the number of students across different academic programs using `Program_Clean`.
* **Attendance Analysis:** Student attendance was summarized and compared across academic programs.
* **Academic Status:** The distribution of students across **Good Standing, At Risk, and Unknown** categories was analyzed using percentages.
* **Midterm Performance:** Total Midterm Scores were analyzed by academic program. For example:

  * **Data Science:** 3,940.5
  * **Computer Science:** 3,938.7
  * **Business Administration:** 3,861.6
* **Interactive Slicers:** Slicers were connected to the Pivot Tables to allow users to quickly filter and explore different categories within the dataset.
